付箋の操作の一覧

同じ内容は、リポジトリの shortcuts.md にもあります。

書式のショートカット

操作キー付く書き方
太字Ctrl+B**文字**
斜体Ctrl+I*文字*
取り消し線Ctrl+Shift+X~~文字~~
インラインコードCtrl+E`文字`
リンクCtrl+K[文字]()（URLを選んでいれば [](URL)）
見出し1 / 2 / 3Ctrl+Alt+1 / 2 / 3# / ## / ###（同じ見出しでもう一度押すと外れる）
番号つきリストCtrl+Shift+71.
箇条書きCtrl+Shift+8-
引用Ctrl+Shift+9>
コードブロックCtrl+Alt+C``` で囲む（1行だけ選んでいてもブロックになる）
  • 同じキーをもう一度押すと、外れるものが多いです（太字・斜体・取り消し線・リスト・引用・コード）。
  • 複数行を選んでいれば、選んだ行すべてに効きます（リスト・引用）。

/ コマンド（行頭か、空白のあとに / を打つ）

候補が出ます。上下キーで選んで Enter か、続けて打って絞り込めます。選ぶと、打った /xxx は消えて、その行が変わります。

コマンド内容
/h1 /h2 /h3見出し1〜3
/bullet箇条書き
/number番号つきリスト
/todoチェックボックス（- [ ] ）
/quote引用
/codeコードブロック（カーソルは中）
/divider区切り線（***）
/red /orange /green /blue /purple /gray文字色の入れ物（<span style="color:…"></span>、カーソルは中）
  • URL の https:// や、a/b、2026/11 のように、単語の途中にある / では出ません。

@ コマンド（行頭か、空白のあとに @ を打つ）

コマンド入るもの
@today今日の日付（2026-11-10 の形）
@tomorrow / @yesterday明日 / 昨日の日付
@now現在の時刻（10:30 の形）
@datetime日付と時刻
@todoチェックボックス（- [ ] ）

編集中のキー

操作キー・動き
リストを続けるリストの行で Enter（次の記号が付く）
リストを終える中身が空のリスト行で Enter（1回で終わる）
インデントTab（リストの入れ子など）
元に戻す / やり直すCtrl+Z / Ctrl+Y
URLを開くCtrl+クリック（普通のクリックは編集のため開かない。[ラベル](URL) は、ラベルの上で開く）
チェックボックスを切り替える- [ ] の「☐」をクリック（[ ] と [x] が入れ替わる）
記号を出すその行にカーソルを置く（カーソルのない行では、記号が隠れる）
記号を常に出すタイトル行の▾ →「Markdownの記号を常に表示」
ブロックの種類を変える行の左に出る「⋮⋮」をクリックして、選ぶ（テキスト / 見出し1〜3 / 箇条書き / 番号つき / チェックボックス / 引用 / コード）

付箋の窓

操作ボタン・動き
書式のツールバーを出す / 隠すタイトル行の「Aa」
付箋の色を変えるタイトル行の🎨
前面に固定する / 解除するタイトル行の📌
付箋の一覧を開くタイトル行の▾ →「📋 付箋の一覧を開く」
この一覧を開くタイトル行の▾ →「⌨ ショートカット一覧」
閉じる（付箋は残る）タイトル行の✕
ファイルの場所を開く左下の「📂 場所」
片付ける（.trash へ移す）左下の「🗑 片付ける」を、2回押す（1回目は赤くなり、3秒で戻る）
窓を動かすタイトル行をドラッグ

一覧窓・トレイ

操作動き
一覧を開くタスクトレイのアイコンを左クリック（付箋の▾メニューからも開けます）
新規付箋 / すべて前面へ / 終了タスクトレイのアイコンを右クリック
付箋を開く一覧の行をクリック
フォルダを追加 / 外す一覧窓の「フォルダを追加…」/ フォルダ名の「×」
フォルダをエクスプローラーで開くフォルダ名の「📂」

文字色について

Markdownに文字色の標準がないため、<span style="color:red">文字</span> と書きます。

Agentやスクリプトからの操作

コマンドラインから、付箋の窓を開く・動かす・前面に固定する・閉じることができます。使い方は、READMEの「Agentやスクリプトからの操作」を見てください。
