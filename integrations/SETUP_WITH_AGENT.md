# Agentにセットアップを依頼する

このページのリンクをAgentに渡し、「この手順でセットアップして」と依頼してください。以下は、そのPCで作業するAgent向けの依頼文です。

---

Markdown Sticky NotesのCodex／Claude連携を、このPCにセットアップしてください。

- リポジトリ：https://github.com/hogawish/markdown-sticky-notes
- 導入入口：[Agent連携のREADME](README.md)
- 個別手順：[Codex](codex/README.md) ／ [Claude](claude/README.md)

目的は、**Agentが人間の返事を待っているときやComputer Use中に付箋を表示し、終了後は終了時刻付きでアーカイブすること**です。CodexとClaudeの両方で使いたいです。

## お願いする作業

1. 連携のREADMEとCodex／Claudeそれぞれの手順を読み、このPCのアプリ・Node.js・Agentのバージョンと対応状況を確認してください。既に導入済みなら再利用してください。
2. 必要ならMarkdown Sticky NotesとNode.jsを導入し、付箋の保存先フォルダをアプリに登録してください。
3. Codex用の監視とClaude用のHookをセットアップしてください。既存設定は保全し、必要な項目だけ追加してください。同じHookや監視がある場合は重複登録しないでください。
4. Codexの監視はWindowsログオン時に自動復帰するようにしてください。二重起動とAgent／モデルの定期起動は避けてください。
5. repo rootで `node integrations/test.cjs` を実行してください。その後、実際の質問→付箋表示→人間の回答→終了時刻付きアーカイブまで、両方で確認してください。Agentからの連絡を人間の回答と誤認しないことも確認してください。実イベントで確認できない機能は未確認として残してください。

Codex連携は非公開イベント形式に依存する実験的な方式です。Claude連携にも確認済み範囲と既知の制約があるので、READMEとこのPCでの結果を照合してください。手順が対応しない場合は、無理に設定を当てはめず、利用できる範囲と不足条件を報告してください。

## 設定と操作

PC固有のチャットID・パス・ログ・実行状態はローカルだけに保存し、Gitへcommit／pushしないでください。実際のチャット参照先を使い、別PCのIDや付箋履歴を流用しないでください。

このPCに適用される管理ポリシーや承認を迂回しないでください。既存のAgent設定を丸ごと上書きしたり、別PCの信頼済み情報を移したりしないでください。

通常のセットアップはそのまま進め、**私の操作・管理者権限・Hookの承認などが必要になったところだけ、具体的な操作を教えてください。** 必要な権限や判断が不足する作業は保留し、独立して進められる作業を続けてください。PCの再起動やサインアウトは、確認なしに行わないでください。

## 完了時の報告

- Codex／Claudeそれぞれの動作確認結果と未確認事項
- 配置先・付箋保存先・起動タスク名
- 起動／停止／更新／復旧の方法

ローカルの設定場所はこのPCのユーザーへ報告し、秘密情報やチャット本文を公開repoへ送らないでください。
